# 月亮茶屋桌宠测试记录

测试在 Windows x64、Node.js 24.19.0、Electron 45.3.4 下执行。`npm test` 编译两组 TypeScript 并执行 11 个自动化用例，全部通过。桌面端到端测试使用隔离的用户数据目录。模型与检索服务通过仅监听本机的测试服务提供确定性响应。

| 验收条目 | 测试记录 |
|---|---|
| A01、A02、A03 | Electron 实际加载透明置顶窗口及 PNG。驱动主进程测试坐标，验证纯白与透明区域调用了不同的原生鼠标忽略状态。拖拽触发动作与窗口坐标变化，释放后回待机。 |
| A04、A12 | 测试滚轮增长、宽高比、最小值、最大值和多屏负坐标。实机首次发现 400 DIP 请求在当前 DPI 下得到 401 DIP，调整 Win32 物理像素取整后重跑，实测限制为 400 DIP。 |
| A05、A06、A07 | 加载 10 份清单，切换月铃服装和狐狸角色时渲染新帧。角色点击触发单次反馈与相邻聊天窗口，关闭聊天窗后可恢复桌宠操作。自定义菜单动作的点击适合在答辩环境复验。 |
| A08、A09、A10 | 实际 Electron IPC 收到逐块 Ollama NDJSON。`/search 桌宠` 请求本机 SearXNG 测试接口，网页摘要进入模型请求，聊天显示来源。月铃的历史在换装后保留，星野读取独立历史。 |
| A11、A15 | 测试 IPC 显示与隐藏，校验越界角色包、空白遮罩和无循环待机的清单。托盘菜单手动操作、文件对话框导入和退出可在答辩环境复验。 |
| A13、A14、A16 | 模型不可用、超长输入、空搜索词、JSON 被拒绝、流提前结束和云端显式启用通过测试。用测试请求确认本地优先；关闭云端时无兼容 API 调用。 |
| A17 | 设置与聊天历史从磁盘重读通过测试。登录启动需在安装版手动开启后复验。 |
| A18 | Forge 生成 Windows x64 Squirrel 安装包和便携包。实际启动打包后的 `MoonTeahouse.exe`，确认能从 ASAR 渲染内置 320 像素角色帧并读取 10 份清单。 |

真实模型的生成效果与公开搜索引擎的可用性取决于安装环境。真实 Ollama 推理、在线 ddgs 检索及登录时启动属于部署环境验收项。

## 1.1.0 DeepSeek 升级验证

该版本的 17 项自动化测试覆盖旧设置兼容、本地优先、独立密钥、网页搜索和阅读的显式调用、Unicode 引用位置、流式中断、内容审核和常见服务错误。Electron 端到端测试使用模拟 DeepSeek 接口，验证设置保存、密钥加密、模型检测、流式搜索进度、正文引用和本地历史。真实上线连接需要用户的 DeepSeek API 密钥。

## 1.2.0 自由搭配与拖曳回归

20 项自动化测试包含全部上衣与下装的组合校验、颜色与角色边界、原套装与自定义搭配的持久化。实机 Electron 端到端用例检查试衣间里的 24 张单品卡、独立选择与套用保存、透明区及命中区，以及连续 42 次拖曳移位时窗口宽高保持一致。拖曳和窗口复位使用已保存的逻辑尺寸，滚轮和尺寸设置负责修改该尺寸。

## 1.3.0 单品插画重绘

`npm test` 的 21 项测试全部通过，新增检查验证 24 张独立的图稿均为 8 位通道的 RGBA PNG。Windows Electron 测试打开试衣间，确认 24 张单品缩略图均可加载，从三位角色的待机、两个拖曳帧与两个挥手帧生成并检查 234 张合成结果。通过界面套用上衣、下装、发型及独立的发色与瞳色，检查合成帧、像素命中、点击后聊天窗口，以及 42 次拖曳移位期间的窗口尺寸。实际运行打包后的程序，确认旧版保存的搭配和尺寸可恢复，24 张插画均可从 ASAR 读取和解码。

## 1.4.0 角色专属表情与动作

`npm test` 的 22 项测试全部通过。检查 10 套内置角色包只获得所属角色的三段动作，导入角色包仍使用自己的点击动作。Windows Electron 实机测试覆盖试衣间切换角色、专属动作按钮和自动返回待机。检查了 288 张原套装及混搭样例的动画帧，验证可见身体与画布留白。打开托盘菜单触发动作时，桌宠窗口位置与大小保持一致，像素命中范围随身体动作变化。逐一点击三个角色，确认播放各自的反应并打开聊天。

## 1.5.0 本机 DeepSeek

24 项自动化测试覆盖旧版设置迁移、模型缺文件时的提示、独立本机地址与身份验证、推理正文的流式解析，以及 Ollama 和 DeepSeek 云端路径的回归。Windows 实机从成品 ASAR 启动，自动载入量化版 DeepSeek-R1-Distill-Qwen-1.5B，通过聊天窗口发送问候并收到真实模型的回答。单独验证了推理端口只绑定环回地址、模型接口拒绝未经认证的请求、正常退出后端口关闭。

## 1.5.1 聊天窗口尺寸

25 项自动化测试通过。Windows 实机运行成品 ASAR，在设置页点「套用」及「保存设置」分别调整聊天窗口的宽高，确认玩偶的实际窗口尺寸与位置未变化。通过托盘自定义玩偶尺寸时，聊天窗口的宽高保持原值。关闭并重新打开聊天，以及重新启动整个应用后，均恢复已保存的尺寸。额外验证了旧版设置读取默认聊天宽高、拒绝无效尺寸和小屏幕下的尺寸限制。

## 1.6.0 随机点击动画

25 项自动化测试通过，覆盖 10 套内置造型的三段专属动画和五段随机动作、随机选择的相邻去重，以及导入角色包的既有点击行为。Windows Electron 检查了三位角色的原套装和混搭样例共 672 张帧，连续九次原生点击均播放新动作。聊天打开后，仍露出的桌宠允许点击，聊天窗口覆盖的区域由聊天接收。试衣间显示全部动作，播放结束后回待机，桌宠窗口位置和大小保持一致。

## 1.7.0 单关节动画

25 项项目测试通过。Windows Electron 实测 56 个单关节样例，确认目标部位的像素有明显变化，对照部位保持原像素。检查三角色的预设和混搭共 960 个动画帧，画布留白至少 15 像素。还验证试衣间的关节选择、角度归零、橘栗的尾巴选项，以及点击桌宠时聊天正常开启和窗口尺寸不变。

## 1.8.0 透明视频动画

26 项项目测试通过。用 Windows Electron 解码十套造型的 110 段 VP9 WebM，逐段校验画布尺寸、时长、透明边缘和可见身体，另用色块测试验证半透明像素。检查帧命中数据与画面帧数一致。运行成品 ASAR 验证透明播放、范围读取、原生鼠标穿透、拖曳时窗口尺寸不变、连续点击选择不同动作、视频结束回待机、聊天开启和旧 PNG 角色包。通过试衣间套用搭配后，11 段动画及其命中数据写入缓存，重启后可直接播放已生成的片段。

## 1.8.1 移除三段点击动作

27 项项目测试通过。十套造型合计保留 80 段透明影片和对应的逐帧命中资料。运行 Windows 成品确认托盘、试衣间和混搭快取中已移除指定动作，连续点击交替播放跳舞和打瞌睡。

## 1.8.2 移除跳舞

27 项项目测试通过。运行 Windows 成品确认托盘、试衣间和既有混搭缓存均已移除跳舞。连续点击每次重新播放打瞌睡，最后一段播完回到待机。

## 1.8.3 修正歪头嗅闻的嘴部残影

28 项项目测试通过。解码并对比橘栗三套造型修正前后的抽样影格，确认多画的嘴线消失。Windows 成品能从托盘播放修正后的内置和混搭动画，播完回待机。既有混搭的旧嗅闻片段会重新生成，其余片段可复用。

## 1.8.4 重制招手和简化动作选单

28 项项目测试通过。十套内置造型的招手视频均为 2.25 秒。对比三位角色的原套装及混搭招手影格，确认旧爱心及重复手部画面已清除。实测托盘和试衣间仅提供手动播放的动作，待机与拖曳仍由桌宠自动触发。用隔离的混搭缓存验证旧招手片段会重新生成并在结束后回待机。

## 1.8.5 移除星野

28 项项目测试通过。Windows 成品验证原先选择星野的配置会切回月铃，托盘和试衣间列出月铃与橘栗，星野的内置资源无法再读取。验证两位角色可以切换、既有聊天历史仍在，并检查 7 套造型和 49 段内置影片的校验值与上版一致。

## 1.9.0 本机千問

29 项项目测试通过。Windows 成品通过聊天设置从本机 DeepSeek 切换到 Qwen2.5 1.5B，千問在聊天窗口返回真实中文回复。切回 DeepSeek、再选千問后，先前的聊天记录仍可读取。模型服务只使用环回地址，切换后旧服务端口关闭，无有效认证的模型请求会被拒绝。
